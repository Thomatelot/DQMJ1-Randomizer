# Changelog

## v1.0.0 — first public release (script version 3.3)

- Wild monster, trainer and boss randomization; the overworld model and walking animation follow the new monster.
- Per-group rank mix (F to X, plus Incarni "I"), "same rank" and "keep difficulty" modes.
- Per-group level boost (percent and flat).
- Starter replacement (any monster or random) — reported working in game.
- Level map (stretch the game's 1-40 enemy levels to e.g. 1-99) and experience-per-kill controls.
- Protections: Slime Challenge slimes kept, Scout Proficiency Test safety, "has no idea what to do" fix for skill-less donors.
- Local web interface plus a full command line, seed option, spoiler log, diagnostics.
- Single file, Python 3 standard library only.
- Experimental: visual-only hero look.
